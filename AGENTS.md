# AGENTS.md — императивные инструкции для агентов

## Что это за репо
github-runbook — мануал настройки GitHub «человеком для человека»:
стандарт настройки для всех репо аккаунта. Аккаунт общий — чужие агенты
публикуют параллельно.

## Правила пополнения
- Новый факт GitHub → сначала live-тест (реальный код ответа) или веб-проверка
  → затем запись в SOURCES.md (сквозная нумерация A-…)
- Новая глава: сквозная нумерация `0N-*.md` + строка в карте README
- Приводить только проверенные команды (с реальными кодами ответов)

## Жёсткие правила (DO NOT)
- НЕ удаляй журнал верификации и НЕ правь A-записи задним числом (только дописывай)
- НЕ вставляй живые токены/секреты в примеры (CI проверяет паттерн github_pat_…)
- НЕ делай force-push; перед пушем — fetch и ff-merge

## Definition of Done
1. Файл отражён в карте README
2. Новые утверждения — в SOURCES.md
3. CI зелёный; ff-merge перед пушем
