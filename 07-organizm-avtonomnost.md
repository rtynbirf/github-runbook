# 07. Организм: автономность репозиториев

Мировые практики дают органы поодиночке: CI, боты зависимостей, бэкапы, релизы.
Принцип клетки (аккаунт `cell65`): автономность = полная инструкция собственного
воспроизводства + метаболизм без внешнего управления. Критерий — **тест
восхождения**: из одного bundle незнакомец (человек или агент) восстанавливает
код, понимает «зачем», проверяет «работает» и продолжает дело — без единого
вопроса извне.

## Органы (внедрены 01.11.2026 во все рабочие репо)

| Орган | Файл | Что делает |
|---|---|---|
| Метаболизм | `.github/workflows/ci.yml` | тесты/инварианты на каждый push (PAC 28/28; CSV 5/6/5/6; каркас эпох; целостность ранбука) |
| ДНК агентов | `AGENTS.md` | императивный контракт: карта репо, команды, DO NOT, Definition of Done |
| Самовоскрешение | `RESTORE.md` | 5 команд из bundle + где взять bundle + ключевые точки |
| Иммунитет | `.github/dependabot.yml` | недельные обновления github-actions-зависимостей |
| Размножение | `.github/workflows/bundle-backup.yml` | cron пн 03:00 UTC → artifact, хранение 90 дней (live: dispatch 204, зелёный run, bundle-артефакты — SOURCES A-21…A-23) |
| Ритм релизов | `.github/workflows/release.yml` | тег `v*` → Release с автозаметками (расширение — с zip) |
| Нервная система | `.github/ISSUE_TEMPLATE/` | дефект / идея / дефект верификации |

## Источники стандартов (проверены поиском 01.11.2026)

- **AGENTS.md** — открытый стандарт инструкций для агентов (императивные правила,
  точные команды, отрицательные примеры, DoD): https://agents.md
- **OpenSSF Scorecard** — автопроверка лучших практик: https://scorecard.dev
  (квартальный самоаудит: `https://scorecard.dev/viewer/?uri=github.com/rtynbirf/<репо>`)
- **Правило 3-2-1** для бэкапов: git-история (GitHub) + артефакты Actions +
  локальные bundle владельца.

## Ограничения Free-плана и компенсации (проверено live, SOURCES A-14)

- Защита веток на приватных репо недоступна → компенсация: ff-only-дисциплина
  в AGENTS.md + tripwire-антифорс (появился у чужого агента в windows-full-report)
  + bundle-ритуал.
- Actions-минуты приватных репо: 2000/мес; cron-бэкап тратит ~1 мин/нед — запас 40-кратный.
- Ручной тест бэкапа (`workflow_dispatch`) требует токен с правом **Actions: write**:
  без него `POST …/dispatches` → 403 «Resource not accessible by personal access
  token» (SOURCES A-17); с ним — **204, и бэкап отработал зелёным во всех четырёх
  репо** с bundle-артефактами на 90 дней (SOURCES A-21…A-23). Плановый cron
  выполняет сам GitHub.

## Смерть носителя ≠ смерть дела

Инструкция переживает всех (теорема аккаунта): каждый репо содержит инструкцию
собственного воскрешения (RESTORE.md), каждый факт — источник (SOURCES.md),
каждое правило — императив для агентов (AGENTS.md). Не мы обслуживаем репо —
репо обслуживает дело и сигналят issue'ом, когда больны.
