# 02. Все флаги Settings → General по-человечески

Каждый флаг: **что делает → наш выбор → почему**. Всё ниже применено live к трём репо
(`PATCH /repos` — HTTP 200 на каждом; см. `SOURCES.md`).

## Блок «Repository name / Description / Topics»

| Флаг | Что делает | Выбор | Почему |
|---|---|---|---|
| Repository name | Имя = часть URL | осмысленное, латиница-дефис | имя читают люди и агенты |
| Description | Подпись под именем везде | 1–2 предложения, по-русски | через полгода это единственная аннотация |
| Website | Ссылка над README | пусто/ссылка на Pages | для домашних репо обычно не нужна |
| Topics | Метки для поиска | 5–11 штук, строчные, через дефис | поиск по аккаунту становится мгновенным |

Проверенный набор топиков: `chrome-extension, mv3, proxy, pac, dnr, adblock, webrtc,
privacy, anti-censorship, sovereign-node, sing-box` (пуш топиков — HTTP 200).

## Блок «Features» (включение разделов)

| Флаг | Что делает | Выбор | Почему |
|---|---|---|---|
| Issues | Список задач/багов | **ON** | единственная штатная доска задач; задачи переживают сессии |
| Discussions | Форум внутри репо | OFF | для работы одного человека и агентов — шум |
| Projects | Канбан-доски | OFF | файлы и issues покрывают всё; доски дублируют |
| Wiki | Отдельная вики | OFF | **документация живёт в репо**: версионируется тем же git |
| Sponsorships | Кнопка «спонсировать» | OFF | личные репо |

Железное правило: **всё в репо**. Wiki и Discussions не версионируются git'ом —
значит, не переживают ничего надёжно.

## Блок «Pull Requests» (комфорт merge-кнопок)

| Флаг | Что делает | Выбор | Почему |
|---|---|---|---|
| Allow merge commits | Кнопка «Merge» | ON | классика для слияния линий разных агентов |
| Allow squash merging | Сжать PR в 1 коммит | ON | когда ветка-черновик — один чистый коммит |
| Allow rebase merging | Переписать коммиты поверх | ON | линейная история без merge-коммитов |
| Allow auto-merge | Слить PR сам, когда пройдут проверки | ON | агент ставит и уходит |
| Auto-merge: allow update branch | Обновить ветку кнопкой, если отстала | ON | меньше ручных ребейзов |
| Delete branch on merge | Удалить ветку после слияния | ON | ветки-мусор не копятся |
| Use squash PR title as default | Заголовок squash = название PR | ON | история читаемая без правки |
| Squash commit title/message | Что писать в сжатом коммите | `PR_TITLE` / `PR_BODY` | то же, но явно зафиксировано |
| Merge commit title/message | То же для merge-коммитов | `PR_TITLE` / `PR_BODY` | единообразие |
| Web commit signoff | Требовать signed-off-by | OFF | личный аккаунт, не корпорация |

## Блок «Pushes» и прочее

| Флаг | Что делает | Выбор | Почему |
|---|---|---|---|
| Limit merges to deploy branch | Ограничить слияния в «deploy»-ветку | OFF | нет спец-веток деплоя |
| Template repository | Делать репо шаблоном для новых | OFF | шаблоном служит ранбук, а не кнопка |
| Archive | Заморозить репо (read-only) | OFF | только для мёртвых дел |
